# C# Task Manager

A simple console-based task management application built with C# and .NET.

## Features

- Add new tasks
- View current tasks
- Mark tasks as completed
- Delete tasks
- Save tasks between sessions using JSON
- Validate menu selections and task numbers

## Technologies

- C#
- .NET
- JSON
- Git
- GitHub

## What I Learned

This project helped me practice object-oriented programming, file handling, JSON serialization, input validation, debugging, and source control.
